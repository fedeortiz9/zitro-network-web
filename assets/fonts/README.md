# Zitro Network — Font Documentation & Licenses

This directory contains the self-hosted web font assets utilized by Zitro Network. All fonts are served locally under permissive open-source licenses without third-party network dependencies.

---

## 1. Instrument Sans

- **Designer / Foundry**: Roderick Kavon, Instrument Ventures, Inc.
- **Upstream Repository**: [https://github.com/googlefonts/Instrument-Sans](https://github.com/googlefonts/Instrument-Sans) / [https://instrument.com](https://instrument.com)
- **License**: SIL Open Font License, Version 1.1
- **License File**: [`OFL-Instrument-Sans.txt`](./OFL-Instrument-Sans.txt)
- **Artifact Details**: WOFF2 web font builds optimized for modern browsers
- **Weights Included**:
  - Regular (`400`): `instrument-sans-400.woff2`
  - Medium (`500`): `instrument-sans-500.woff2`
  - SemiBold (`600`): `instrument-sans-600.woff2`
  - Bold (`700`): `instrument-sans-700.woff2`
- **Usage**: Primary typography for headlines, body copy, and UI controls.

## 2. IBM Plex Mono

- **Designer / Foundry**: Mike Abbink, Bold Monday, IBM Corp.
- **Upstream Repository**: [https://github.com/IBM/plex](https://github.com/IBM/plex) / [https://www.ibm.com/plex](https://www.ibm.com/plex)
- **License**: SIL Open Font License, Version 1.1
- **License File**: [`OFL-IBM-Plex-Mono.txt`](./OFL-IBM-Plex-Mono.txt)
- **Artifact Details**: WOFF2 Latin-subset web font builds
- **Weights Included**:
  - Regular (`400`): `ibm-plex-mono-400.woff2`
  - Medium (`500`): `ibm-plex-mono-500.woff2`
  - SemiBold (`600`): `ibm-plex-mono-600.woff2`
- **Usage**: Technical data labels, badges, status metrics, timers, and code readouts.
